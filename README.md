# Incognitive Waitlist

Soft Hub patch for [incognitive.ai](https://incognitive.ai) waitlist.

## Install

```text
dist/incognitive-waitlist-1.1.0.softhub.zip
```

Soft Hub → Patches → drop the zip (or GitHub / Patch Radar).

## Build

```bash
python3 scripts/build_plugin.py \
  incognitive-waitlist \
  dist/incognitive-waitlist-1.1.0.softhub.zip
```
